# PrototypeEngine
# ブランチについて
※ブランチの種類   
・release：閲覧用のブランチ。プロジェクトを確認する場合はこのブランチでお願いします   
・main：プロジェクト本体のブランチ。作業の最新状態を保持しているもの   
・debug：作業用ブランチ   
# プロジェクト概要
このプロジェクトはSDL3とOpenGLをベースに作成しています。  
またエンジン部分の処理はImGui(詳しくは下記のURLを参照)を使用して作成しています。   
このプロジェクトの詳細は下記のWeb版ポートフォリオで確認が出来ます。
