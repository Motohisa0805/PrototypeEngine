# PrototypeEngine
# プロジェクトについて
このプロジェクトは既存のゲームエンジンを模倣した自作エンジンになります。   
詳細は同フォルダ内の「Documents」フォルダ内のREADME.mdを閲覧ください   
# 作品制作の意図
ゲームの低レイヤーの設計、構造への理解力向上を考え制作を始めました。   
Unityで複数のゲーム制作を経験し、仕様作りへの知識は身に付きましたが   
ゲームの基本的な設計、構造への理解が足りないと感じ、エンジン制作を通してゲームの低レイヤー分野を   
磨こうと考えました。   
具体的には3Dモデルの描画、2D画像の描画、物理的な当たり判定、物理的挙動(効率的、パフォーマンスを考えた自由な挙動が作れるか)、   
グラフィック面(光、影、スカイボックスなど)などのゲームの仕様作りに関わる部分の制作に力を入れています。
